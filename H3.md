Install Debian on VirtualBox - Updated 2024

Using VirtualBox we can install Linux even on Windows and Mac, before we can completely move to Linux. We can also download Debian Iso image by searching in google as Googling/Duckducking "Debian live iso" or use the link https://www.debian.org/download. Debian live only take couple of gigabytes and take few minutes to download. 


Create a New Virtual Machine


Install VirtualBox

Start the VirtualBox

From the menu click New and new window opens up

Write the name of the Virtual Machine, select the ISO image downloaded, select compatible OS version, specify the required virtual hardware, select EFI, and click finish
