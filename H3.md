1.First check if the internet is working.</br>
2.After confirming the connection insert "**$ sudo apt-get update**" in the terminal, which checks for the updates. Do not type in **$** as it is already typed in the terminal</br>
3. "**sudo apt-get -y dist-upgrade**", if this does not work then use "**sudo dpkg --configure -a**".</br>
4. **sudo apt-get -y install ufw**</br>
5. **sudo ufw enable**</br>

If everything works then we have successfully installed the **Linux Desktop**.

<h1>Command Line Basics Revisited</h1>
Command line has survived the test of time and was there before the internet and any type of operating system.

<h2>Lets look at what few command lines does. Remember we do not have to type **$**</h2>

**$ pwd** prints the working directory.

**$ ls** shows the list of files in working directory.

**$ cd terosdir/** changes the directory to "terosdir" if there is any directory named terosdir.

<h3>File Manipulation</h3>
Easiest text editors are pico and nano.

**$ nano FOO.TXT** where FOO.TXT is the name of the file. Using this we can edit the file named FOO.TXT.

**$ mkdir NEWFOLDER** makes a new folder.

**$ mv OLDNAME NEWNAME** this command helps move directory named "OLDNAME" inside "NEWNAME" directory, if there is not directory named "NEWNAME" then it renames "OLDNAME" to "NEWNAME" directory.

There are many other commands in Linux and we can get better at it with practice.
