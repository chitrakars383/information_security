This reading describes the basic single-way processes that give the foundations of digital security today. The main concepts could be outlined as follows:

2.3 One-Way Functions

One-Way Functions are computationally easy to compute in one direction ($x to f(x)) but computationally impossible to undo in the other direction (f(x) to x)) otherwise without taking millions of years.
The Reality Check: Mathematically, we cannot yet analyze that they actually exist we just use functions that are now too hard to be solved by any known computer (such as operations in finite fields).
Trapdoor One-Way Functions: It is more specialized form, which has a secret. Although the common people cannot undo the given purpose, a user with the secret key (the trapdoor) can undo the purpose with ease. This is where the public-key encryption is based.

2.4 One-Way Hash Functions

The "Fingerprint": A hash accepts an input of variable length and transforms it into a fixed length output. It serves as a special digital signature of a bit of information.
Core Properties:  One-wayness: It is not possible to retrieve the original file using a hash.
Collision-resistance: It is almost impossible to have two different files with the same hash.
Avalanche Effect: When changes to single bit of the input is made, the output is given by changing the half of the original bits, and the outcome appears chaotic.
Their application in practice: They are applied to confirm data integrity (that a file or financial transaction has not been compromised) without transfer of the whole file.

Message Authentication Codes (MAC)

Keyed Hashing: MAC is simply a one way hash type that must be computed or verified using a secret key.
Authentication: A MAC is different to a standard hash in that anyone can verify the integrity and the origin of a message, whereas only a person holding the secret key in question can.
